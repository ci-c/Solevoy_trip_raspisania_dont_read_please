# Система управления агентами

Этот каталог содержит актуальные материалы для работы ИИ-агентов.

## Структура

- `agent_policies.yaml` — роли, приоритеты и настройки планировщика.
- `initial_tasks.yaml` — шаблоны стартовых задач для каждой роли.
- `agent_system_cli.py` — Python-CLI/оркестратор (агенты, задачи, коммуникации).
- `AGENT_PLATFORM_GUIDE.md` — руководство по новой платформе.
- `AGENT_PLATFORM_GUIDE.md` — руководство по новой платформе.
- `CLAUDE.md` — вспомогательные заметки для Claude.
- `legacy/` — архив устаревших инструкций.

## Основные принципы

1. Любые изменения в ролях/правилах вносятся в `agent_policies.yaml`.
2. Промпты ролей лежат в `ai_docs/prompts/roles/` и попадают в `welcome.md` прионбординге.
3. Состояние хранится в `ai_docs/state/agents.yaml`, `issues.yaml`, `events.yaml`, `communications.yaml` и в каталогах `ai_docs/state/agents/<ID>/`.
4. `todo.txt` является экспортом активных Issues; редактировать файл вручную не нужно.
5. Shell-скрипты не используются; все операции — через Python CLI/API.
6. Перед правками документации сверяйтесь с файлами в `system/`.

Дополнительные ссылки появятся после внедрения нового CLI.
