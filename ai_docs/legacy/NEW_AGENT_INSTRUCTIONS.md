# Инструкции для новых агентов

## 🎯 ВАЖНО: Роли назначаются автоматически!

**НЕ ВЫБИРАЙТЕ РОЛЬ САМИ!** Система автоматически определит оптимальную роль для вас на основе текущих потребностей проекта.

## Быстрый старт

### 1. Запросите назначение роли
```bash
cd /home/c/Documents/Project/P-2
./role_manager.sh assign "Ваше имя"
```

### 2. Система автоматически:
- Проанализирует потребности проекта
- Назначит оптимальную роль
- Зарегистрирует вас в системе
- Создаст персональные команды

### 3. Загрузите команды
```bash
source agents/YOUR_ID/commands.sh
```

### 4. Изучите промпт для вашей роли
```bash
# Промпт будет показан после назначения
# Или найдите его в: ai_docs/PROMPTS/ROLE_AGENT_PROMPT.md
```

### 5. Начните работу
```bash
my_tasks
```

## Доступные роли

- **BE** - Backend Developer (серверная логика, база данных)
- **FE** - Frontend Developer (UI/UX, интерфейс бота)
- **QA** - Quality Assurance (тестирование, качество кода)
- **DO** - DevOps Engineer (развертывание, мониторинг)
- **PO** - Product Owner (управление backlog, планирование)
- **SM** - Scrum Master (координация, процессы)

## Логика назначения ролей

Система назначает роли по приоритету:

1. **Критические потребности** - если нет агентов для критических задач
2. **Баланс команды** - равномерное распределение ролей
3. **Приоритет ролей** - BE > FE > QA > DO > PO > SM

## Команды для управления ролями

### Архитектор может:
```bash
# Назначить роль новому агенту
./role_manager.sh assign "Имя агента"

# Перераспределить роль существующему агенту
./role_manager.sh reassign AGENT_ID NEW_ROLE

# Принудительно назначить роль
./role_manager.sh force AGENT_ID ROLE

# Посмотреть статус ролей
./role_manager.sh status

# Посмотреть доступные роли
./role_manager.sh roles
```

### Агенты могут:
```bash
# Запросить назначение роли
./role_manager.sh assign "Мое имя"

# Посмотреть статус ролей
./role_manager.sh status
```

## Примеры

### Новый агент запрашивает роль:
```bash
./role_manager.sh assign "Backend Specialist"
# Результат: BE_001_v1 - Backend Developer
```

### Архитектор перераспределяет роль:
```bash
./role_manager.sh reassign BE_001_v1 FE
# Результат: BE_001_v1 становится Frontend Developer
```

### Принудительное назначение:
```bash
./role_manager.sh force BE_001_v1 QA
# Результат: BE_001_v1 принудительно становится QA
```

## Формат сообщений агентов

### После назначения роли:
```
[YOUR_ID] Роль получена: ROLE
Готов к работе согласно промпту ai_docs/PROMPTS/ROLE_AGENT_PROMPT.md
+ready +role_assigned
```

### Запрос на перераспределение:
```
[YOUR_ID] Запрос на перераспределение роли
Текущая роль: CURRENT_ROLE
Желаемая роль: DESIRED_ROLE
Причина: ОБОСНОВАНИЕ
+reassignment_request
```

## Важные правила

1. **НЕ ВЫБИРАЙТЕ РОЛЬ САМИ** - используйте `./role_manager.sh assign`
2. **СЛЕДУЙТЕ ПРОМПТУ** - для вашей назначенной роли
3. **СООБЩАЙТЕ О ГОТОВНОСТИ** - после получения роли
4. **ЗАПРАШИВАЙТЕ ПЕРЕРАСПРЕДЕЛЕНИЕ** - если нужна другая роль

---

**Помните**: Система знает лучше, какая роль вам нужна! Доверьтесь автоматическому назначению.
