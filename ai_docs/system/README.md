# Система управления агентами

Этот каталог содержит актуальные материалы для работы ИИ-агентов.

## Структура

- `agent_policies.yaml` — роли и правила доступа.
- `agent_system_cli.py` — Python-CLI для работы с агентами и задачами (вместо shell).
- `AGENT_PLATFORM_GUIDE.md` — руководство по новой платформе.
- `CLAUDE.md` — вспомогательные заметки для Claude.
- `legacy/` — архив устаревших инструкций.

## Основные принципы

1. Любые изменения в ролях/правилах вносятся в `agent_policies.yaml`.
2. Все данные состояния лежат в `ai_docs/state/` (агенты, задачи, логи).
3. Shell-скрипты больше не используются; управление осуществляется через Python CLI.
4. Перед правками документов проверяйте, нет ли более новых версий в `system/`.

Дополнительные ссылки появятся после внедрения нового CLI.
