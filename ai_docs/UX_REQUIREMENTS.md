# UX ТЗ - SZGMU Schedule Bot

## 🎯 ЦЕЛЬ ПРОЕКТА
Создать максимально простой и интуитивный Telegram-бот для студентов СЗГМУ с фокусом на быстрый доступ к расписанию и минимум кликов.

## 🚀 ПРИНЦИПЫ UX

### 1. **МИНИМАЛИЗМ**
- Максимум 3 клика до нужной информации
- Одна функция = одна кнопка
- Никаких сложных меню и подменю
- Понятные иконки вместо текста

### 2. **СКОРОСТЬ**
- Мгновенный отклик на команды
- Кэширование часто используемых данных
- Предзагрузка расписания
- Быстрый поиск по группам

### 3. **ПРОСТОТА**
- Никаких сложных форм
- Автоматическое определение группы
- Умные подсказки
- Один способ сделать каждое действие

## 🔄 ПОЛЬЗОВАТЕЛЬСКИЕ СЦЕНАРИИ

### **СЦЕНАРИЙ 1: Новый пользователь**
1. `/start` → Приветствие
2. "Настройка группы" → Выбор способа
3. "Ввести номер группы" → Ввод "103а"
4. Подтверждение → Готово!

### **СЦЕНАРИЙ 2: Просмотр расписания**
1. `/start` → "Мое расписание"
2. Просмотр на сегодня/завтра
3. При необходимости "На неделю"

### **СЦЕНАРИЙ 3: Поиск другой группы**
1. `/start` → "Найти группу"
2. Ввод номера группы
3. Просмотр расписания

### **СЦЕНАРИЙ 4: Изменение настроек**
1. `/start` → "Настройки"
2. "Изменить группу"
3. Повтор настройки группы
